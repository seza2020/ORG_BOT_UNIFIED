# P4 — Deep Root-Cause Investigation of the Provider → Core Context → Event Contract

## Scope

This phase covers the late-stage deep diagnostic investigation of ORG_BOT_UNIFIED in Paper runtime after major infrastructure stabilization had already been achieved.

The system runtime, wrappers, locking, and observability were broadly functional, but trading activity remained absent or extremely limited. The conversation focused on tracing the true blocker from decision-layer symptoms back into the upstream data path.

This phase ended with the investigation narrowed to a broken contract path between:

market_provider  
→ core_context  
→ meta_events emission

## Objective

Determine the true engineering root cause of persistent no-trade behavior without re-testing already-fixed infrastructure issues.

The main goal was to separate:

- infrastructure faults
- policy/threshold strictness
- strategy edge weakness
- data-path failure

The investigation specifically aimed to explain why `plan_created` remained zero or near-zero despite stable runtime execution and active evaluation.

## What was done

- Reconfirmed canonical launcher flow, single-instance runtime enforcement, wrapper stability, task cleanup, observability logging, and dashboard tooling.
- Verified structural execution of the full decision pipeline.
- Audited downstream symptoms including `alpha_mode OFF`, CHOP dominance, `state_confidence_low`, candidate rejection, and `plan_created = 0`.
- Repaired a confirmed `core_context` bug involving snapshot misuse / `NameError`.
- Parameterized and relaxed regime thresholds, alpha thresholds, and core-context trend scaling under controlled restart + audit cycles.
- Ran repeated INPUT_FRESHNESS audits showing progression from frozen inputs to missing inputs.
- Audited `market_provider.py`, `replay_provider.py`, and `orchestrator.py`.
- Added provider freshness and transparency diagnostics.
- Applied final strict `core_context` invalidation logic for missing market fields.

## What was confirmed

- Infrastructure was not the active blocker.
- A real `core_context` bug existed and was fixed earlier.
- `alpha_mode OFF`, CHOP dominance, and `state_confidence_low` were real downstream symptoms.
- Upstream market inputs degraded from frozen values to absent values.
- Active runtime path used `market_provider`, not `replay_provider`.
- Root cause was narrowed to a broken contract path between:
  - `market_provider`
  - `core_context`
  - `meta_events` emission

## What was rejected

- dual-runtime instability as current dominant cause
- broken runtime startup or event bus
- alpha strictness alone
- regime threshold strictness alone
- FLAT bias hard-off alone
- replay path as the active primary source
- cache-off plus fallback suppression as a complete fix
- strict invalidation patch alone resolving the ambiguity
